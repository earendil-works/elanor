# `@earendil-works/elanor-icons-boiled`

Material Symbols Outlined (20px, weight 400) with a hand-drawn “boil”, as SVG files. React components are published separately as [`@earendil-works/elanor-icons-boiled-react`](./react/README.md).

```ts
import searchUrl from '@earendil-works/elanor-icons-boiled/svg/search.svg';
import metadata from '@earendil-works/elanor-icons-boiled/metadata.json'; // search tags keyed by public icon name
```

The exports match [`@earendil-works/elanor-icons`](../icons/README.md), which has the plain icons; switch between them by changing the package name. Both packages are built by `@earendil-works/elanor-icons`, this one with the boil. See [`LICENSE`](./LICENSE) and [`NOTICE`](./NOTICE).
