# `@earendil-works/elanor-icons-boiled-react`

React components for [`@earendil-works/elanor-icons-boiled`](../README.md).

```tsx
import {SearchIcon} from '@earendil-works/elanor-icons-boiled-react/search';

<SearchIcon aria-label="Search" />;
```

The exports match [`@earendil-works/elanor-icons-react`](../../icons/react/README.md), which has the plain icons. To use the boiled icons inside `@earendil-works/elanor-react` too, redirect its icon dependency; see [plain or boiled](../../icons/README.md#plain-or-boiled).
