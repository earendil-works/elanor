# `@earendil-works/elanor-logos-react`

React components for [`@earendil-works/elanor-logos`](../README.md).

```tsx
import {EarendilLogo} from '@earendil-works/elanor-logos-react/earendil';

<EarendilLogo lockup="horizontal" height={32} />;
```

Props: `lockup` (`horizontal` | `stacked`, omit for the symbol), `monochrome`, `scheme` (`auto` follows the page's `color-scheme`), and `height`.
