# `@earendil-works/elanor-icons-boiled-react`

Material Symbols with a hand-drawn boil as React components. Requires React 18 or 19; no SVG source package is needed at runtime.

```sh
npm install @earendil-works/elanor-icons-boiled-react react
```

```tsx
import {SearchIcon} from '@earendil-works/elanor-icons-boiled-react/search';

<SearchIcon aria-label="Search" />;
```

The exports match `@earendil-works/elanor-icons-react`, which has the plain icons.
