# `@earendil-works/elanor-icons-react`

Material Symbols as React components. Requires React 18 or 19; no SVG source package is needed at runtime.

```sh
npm install @earendil-works/elanor-icons-react react
```

```tsx
import {SearchIcon} from '@earendil-works/elanor-icons-react/search';

<SearchIcon aria-label="Search" />;
```

For the boiled icons, import the same names from `@earendil-works/elanor-icons-boiled-react`.
