# Container

Centers content with inline gutters and an optional width cap. Renders a `div`,
not a main landmark.

<ContainerExample />

## Width and gutters

| Prop    | Values               | Default    |
| ------- | -------------------- | ---------- |
| `width` | `'capped'`, `'full'` | `'capped'` |

Content is capped at `semantic.dimension.size.content.large` (76rem / 1216px),
with `semantic.dimension.space.padding.xLarge` gutters (16px): 1248px maximum outer
width. Container shrinks to fit its parent and adds no block padding.

A Grid inside Container is also capped, even when it spans all tracks; use
`width="full"` to give it more room.

`width="full"` removes the cap but preserves gutters. For edge-to-edge content,
omit Container, or combine `width="full"` with `style={{paddingInline: 0}}`.

```tsx
import {Container, Layout} from '@earendil-works/elanor-react';

<Layout.Main>
  <Container>Centered, capped content</Container>
  <Container width="full">Uncapped content with gutters</Container>
</Layout.Main>;
```

## Styling

Native props, `ref`, `className`, and `style` pass through. Base UI's `render`
accepts an element or render function and merges props and refs.

```tsx
<Container
  render={<section aria-labelledby="reading-title" />}
  style={{maxInlineSize: 'var(--semantic-dimension-size-content-small)'}}
>
  <h2 id="reading-title">A compact reading region</h2>
  <p>Application content.</p>
</Container>
```

`maxInlineSize` includes padding (border-box). To change gutters without changing
the content cap, update the outer maximum too:

```css
.wideGutters {
  padding-inline: var(--semantic-dimension-space-padding-xx-large);
  max-inline-size: calc(
    var(--semantic-dimension-size-content-large) +
      var(--semantic-dimension-space-padding-xx-large) * 2
  );
}
```

Logical properties support RTL. Wide children need their own wrapping or
accessible overflow handling; Container does not clip them.
