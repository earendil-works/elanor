# Container

Centers page content with inline gutters and a maximum width. Use it inside `Layout.Main` or any region that needs a centered column.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Container} from '@earendil-works/elanor-react';

<Container>Page content</Container>;
```

Content is capped at `semantic.dimension.size.maxWidth.content.large` (1216px) with `semantic.dimension.space.padding.xLarge` gutters (16px). Container fills its parent up to that cap, so it also centers in the space left beside a sidebar. It adds no block padding and renders a `div`, not a landmark.

The gutters grow into the device's safe areas, so content stays clear of a notch or rounded corners when a phone is in landscape. Safe areas only apply when the page opts into them with `viewport-fit=cover` in its viewport meta tag; otherwise they are zero and the gutters stay 16px.

## Full width

`width="full"` removes the cap and keeps the gutters. The difference shows only in parents wider than 1216px, so there is no live preview. A [Grid](/components/grid/) inside a capped Container is capped too; use `width="full"` to give it more room.

```tsx
<Container width="full">{/* Uncapped content */}</Container>
```

For edge-to-edge content, omit Container, or combine `width="full"` with `style={{paddingInline: 0}}`.

## Custom element and width

`render` changes the element. `maxInlineSize` includes the gutters (`box-sizing: border-box`).

<Demo example="./examples/custom-element.tsx" />

To change the gutters without changing the content cap, adjust the maximum width too, and keep the safe areas:

```css
.wideGutters {
  padding-left: max(var(--semantic-dimension-space-padding-xx-large), env(safe-area-inset-left));
  padding-right: max(var(--semantic-dimension-space-padding-xx-large), env(safe-area-inset-right));
  max-inline-size: calc(
    var(--semantic-dimension-size-max-width-content-large) +
      var(--semantic-dimension-space-padding-xx-large) * 2
  );
}
```

Container does not clip wide children; give them their own wrapping or scrolling.
