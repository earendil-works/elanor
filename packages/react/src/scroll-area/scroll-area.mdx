# Scroll area

A bounded region with native scrolling and custom scrollbars, such as a long list inside a panel. Not for page scrolling or virtualized lists.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {ScrollArea} from '@earendil-works/elanor-react';

<ScrollArea.Root>
  <ScrollArea.Viewport role="region" aria-label="Release notes">
    <ScrollArea.Content />
  </ScrollArea.Viewport>
  <ScrollArea.Scrollbar>
    <ScrollArea.Thumb />
  </ScrollArea.Scrollbar>
</ScrollArea.Root>;
```

- **Root** needs a bounded height, set directly or by a flex or grid parent.
- **Viewport** is the element that scrolls. Name it, and put `ref`, `onScroll`, and scroll calls here. It's focusable only while content overflows, so keyboard users can scroll it.
- **Content** has padding by default, so scrollbars don't cover text or focus outlines. Add `style={{minWidth: 0}}` when content should shrink or truncate instead of growing wider.
- **Scrollbar** appears only when content overflows.

For right-to-left layouts, set `dir` on the element and `DirectionProvider` to the same direction.

## Styling states

Style the parts with Base UI state attributes:

| Attribute                                      | Meaning                                  |
| ---------------------------------------------- | ---------------------------------------- |
| `data-has-overflow-x`, `data-has-overflow-y`   | Content is larger than the viewport      |
| `data-overflow-y-start`, `data-overflow-y-end` | More content above or below              |
| `data-overflow-x-start`, `data-overflow-x-end` | More content at an inline edge           |
| `data-scrolling`                               | Scrolling is in progress                 |
| `data-hovering`                                | The pointer is over the area (Scrollbar) |
| `data-orientation`                             | Scrollbar and Thumb axis                 |

Don't wrap an element that already has `overflow: auto`. [Sidebar](/components/sidebar/) uses its own scrollbar visibility and overflow cues.
