# Inline code

Code, file names, and commands within running text. For code on its own lines, use [Code snippet](/components/code-snippet/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {InlineCode} from '@earendil-works/elanor-react';

<InlineCode>pnpm install</InlineCode>;
```

Inline code uses `semantic.fontFamily.code` and `semantic.color.text.code` at `semantic.number.fontScale.inlineCode` times the size of the surrounding text, so code in a heading grows with it. The default `soft` variant adds a `semantic.color.background.fill.secondary` fill. Long identifiers wrap.

## Plain

Use `variant="plain"` in headings, tables, and dense text.

<Demo example="./examples/plain.tsx" />

## Program output

Use `render={<samp />}` for output from a program, such as an error message.
