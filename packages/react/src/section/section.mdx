# Section

A named part of a page, with an optional separator line `semantic.dimension.space.gap.large` (24px) below its content. Section adds no border, padding, or width cap.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Heading, Section} from '@earendil-works/elanor-react';

<Section.Root aria-labelledby="members-heading">
  <Section.Content>
    <Heading level={2} id="members-heading">
      Members
    </Heading>
  </Section.Content>
  <Section.Separator />
</Section.Root>;
```

Root renders a `section`; name it with its heading through `aria-labelledby`. Content renders a `div`; lay out its children with [Stack](/components/stack/) or [Grid](/components/grid/). Leave out Separator for no line.

## Separator span

The separator sits in its own 12-column grid with default gutters. `span` sets how many tracks it covers, optionally per container breakpoint. To align content with a shorter line, use a 12-column Grid with default gutters inside Content, as in this demo.

The separator's grid measures its own width, not the parent's tracks. For shared tracks, compose [Separator](/components/separator/) and Grid yourself.
