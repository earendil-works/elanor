# Segmented control

A row of buttons for switching between two to five related options, such as views or periods. Exactly one is pressed. To show different panels, use [Tabs](/components/tabs/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {SegmentedControl} from '@earendil-works/elanor-react';

<SegmentedControl.Root aria-label="Billing period" defaultValue={['monthly']}>
  <SegmentedControl.Item value="monthly">Monthly</SegmentedControl.Item>
  <SegmentedControl.Item value="yearly">Yearly</SegmentedControl.Item>
</SegmentedControl.Root>;
```

The value is an array with one item, as in Base UI Toggle Group. Pressing the selected item would clear it; ignore empty values in `onValueChange` to keep one selected, as the demo does.

## Density

Use `compact` on Root beside compact controls, such as Dropdown filters in a [search and filter bar](/components/search-and-filter-bar/). Each item's touch target keeps the default height, as on compact Dropdown triggers.
