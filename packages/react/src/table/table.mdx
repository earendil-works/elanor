# Table

Shows data in rows and columns for comparing records. For a single record's details, use [Key value](/components/key-value/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Table} from '@earendil-works/elanor-react';

<Table.Container>
  <Table.Root aria-label="Projects">
    <Table.Head>
      <Table.Row>
        <Table.HeaderCell scope="col" />
      </Table.Row>
    </Table.Head>
    <Table.Body>
      <Table.Row>
        <Table.Cell />
      </Table.Row>
    </Table.Body>
  </Table.Root>
</Table.Container>;
```

The parts render native table elements. Container scrolls wide tables horizontally. Name the table with `aria-label` or a caption, and set `scope` on header cells. Align numbers with `align="end"` on both the header cell and the column's cells, so the header lines up with its values.

Cells align to the top, so short cells line up with the first line of taller ones. Table text uses `semantic.typography.primary`, the UI style by default and the prose style inside long-form content (`data-text-context="prose"`), like [Text](/components/text/).

## Two-line cells

`CellPrimary` and `CellSecondary` stack a main value over supporting text in one cell.

<Demo example="./examples/two-line-cells.tsx" />

## Cells that span rows

Cells with `rowSpan` fill the same column in the rows below them. The first and last cell of a row drop their outer padding to line up with the table's edges, so tell later rows which edges spanning cells take with `spannedEdges`. Their first or last cell then keeps its padding and stays in line with its column.
