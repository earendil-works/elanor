# Top navigation menu

The [Top navigation](/components/top-navigation/)'s menu for narrow screens: a button in the bar opens a menu that fills the window below it, with panels that slide to nested sections. For a menu of actions, use [Menu](/components/menu/); for an app's navigation in a drawer, see [Responsive navigation](/components/top-navigation/#responsive-navigation).

## Usage

```tsx
import {TopNavigation, TopNavigationMenu} from '@earendil-works/elanor-react';

<TopNavigationMenu.Root defaultPanel="main">
  <TopNavigation.Root>
    <TopNavigation.Actions>
      <TopNavigationMenu.Trigger aria-label="Navigation menu" />
    </TopNavigation.Actions>
  </TopNavigation.Root>
  <TopNavigationMenu.Popup>
    <TopNavigationMenu.Panel panel="main">
      <TopNavigationMenu.List>
        <TopNavigationMenu.Item>
          <TopNavigationMenu.PanelTrigger panel="docs" />
        </TopNavigationMenu.Item>
      </TopNavigationMenu.List>
    </TopNavigationMenu.Panel>
    <TopNavigationMenu.Panel panel="docs" parent="main" backLabel="Main menu" />
  </TopNavigationMenu.Popup>
</TopNavigationMenu.Root>;
```

Root holds the menu's state and renders no element; put the Trigger in the bar and the Popup after it. The Trigger shows the menu icon, and the close icon while the menu is open. The Popup fills the window below `semantic.dimension.size.topNavigation`. Escape and the Trigger close it; the bar's other controls, such as a theme switcher, leave it open.

Each opening starts at `defaultPanel`. A `PanelTrigger` slides to a nested panel, which starts with a back button and takes focus there. Panels slide with `semantic.transition.movement.disclosure`, instantly when the reader prefers reduced motion. One level of nesting.

Items match [Side navigation](/components/side-navigation/)'s links: `active` marks the current page, or the section that contains it, with the active fill, primary text, and the selected weight.
