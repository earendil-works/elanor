# Menu

A button that opens a list of actions, such as rename or archive. For choosing a value, use [Dropdown](/components/dropdown/); for site navigation, use [Navigation menu](/components/navigation-menu/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Menu} from '@earendil-works/elanor-react';

<Menu.Root>
  <Menu.Trigger />
  <Menu.Portal>
    <Menu.Positioner>
      <Menu.Popup>
        <Menu.Item />
      </Menu.Popup>
    </Menu.Positioner>
  </Menu.Portal>
</Menu.Root>;
```

Choosing an item closes the menu. Run the action in the item's `onClick`.

## Icons and links

`icon` adds a decorative icon before the label and `endAdornment` adds one after it. `Menu.LinkItem` navigates to `href` instead of running an action.

<Demo example="./examples/icons.tsx" />

## Destructive items

`semantic="negative"` marks an item that deletes or removes something. Put it last, after a separator, and confirm it when it cannot be undone.

<Demo example="./examples/negative.tsx" />

## Groups

`Group` and `GroupLabel` name related items; `Separator` draws a line between groups.

<Demo example="./examples/groups.tsx" />

## Touch screens

On touch screens (`pointer: coarse`), the menu takes the size of the system's own long-press menus: each item is at least `semantic.dimension.size.x-large` (48px) tall, a comfortable touch target, in `semantic.typography.ui.primary`, and the popup is at least `semantic.dimension.size.menu` (224px) wide, within the space available, with `semantic.dimension.radius.large` corners. With a mouse it stays compact.
