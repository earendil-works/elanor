# Empty state

Explains why a view has no content and what to do next, such as an empty list or a search without results.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {EmptyState} from '@earendil-works/elanor-react';

<EmptyState.Root>
  <EmptyState.Illustration />
  <EmptyState.Body>
    <EmptyState.Copy>
      <EmptyState.Title level={2} />
      <EmptyState.Description />
    </EmptyState.Copy>
    <EmptyState.Actions />
  </EmptyState.Body>
</EmptyState.Root>;
```

Set the title's `level` to fit the page outline. Illustration and Actions are optional. Copy limits the title and description to 30rem (480px at the default font size), or less in narrower containers.
