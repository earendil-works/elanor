# Page header

The title area at the top of a page, with an optional description and page-level actions.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {PageHeader} from '@earendil-works/elanor-react';

<PageHeader.Root>
  <PageHeader.Row>
    <PageHeader.Title level={1} />
    <PageHeader.Actions />
  </PageHeader.Row>
  <PageHeader.Description />
</PageHeader.Root>;
```

The title always uses heading size 1. Give it `level={1}`; the demo uses `level={2}` because this page already has an H1. Actions wrap below the title when space runs out.
