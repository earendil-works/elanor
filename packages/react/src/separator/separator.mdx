# Separator

A thin line that divides groups of content. Screen readers announce it as a separator.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Separator} from '@earendil-works/elanor-react';

<Separator />;
```

## Vertical

`orientation="vertical"` divides items in a row. The parent needs a height for the line to fill.
