# Drawer

A modal panel that slides in from a screen edge, such as a bottom sheet or mobile navigation. It traps focus, locks page scrolling, and can be swiped away.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Drawer} from '@earendil-works/elanor-react';

<Drawer.Root>
  <Drawer.Trigger />
  <Drawer.Portal>
    <Drawer.Backdrop />
    <Drawer.Viewport>
      <Drawer.Popup>
        <Drawer.Content>
          <Drawer.Title />
          <Drawer.Description />
          <Drawer.Close />
        </Drawer.Content>
      </Drawer.Popup>
    </Drawer.Viewport>
  </Drawer.Portal>
</Drawer.Root>;
```

Popup scrolls within the viewport. Content keeps text selectable with a mouse; add `data-base-ui-swipe-ignore` to controls that handle their own gestures.

When a bottom sheet contains form fields, wrap its Portal in `VirtualKeyboardProvider` inside Root. On touch devices, it keeps the focused field visible above the software keyboard.

## Side panel

`swipeDirection="left"` or `"right"` turns the drawer into a side panel; the default, `"down"`, is a bottom sheet. Directions are physical, so they don't flip in right-to-left layouts.

Close the drawer when the user navigates, with `actionsRef.current.close()` or controlled `open`. Don't hide an open drawer with CSS at a breakpoint; close it instead. Keep its `open` state separate from [Sidebar](/components/sidebar/)'s `collapsed`.

<Demo example="./examples/side-panel.tsx" />

## Nested sheets

Nest a Drawer inside a Popup to stack bottom sheets. With `data-stacked` on each Popup, parent sheets shrink behind the open sheet. Closing a nested sheet returns focus to its trigger.

<Demo example="./examples/nested.tsx" />

## Overlay placement

The application decides how overlays stack. With an elevated header, give `Drawer.Portal` `position: fixed`, `inset: 0`, and `z-index: var(--semantic-number-layer-overlay)`. Leave the backdrop, viewport, and nested popups on their default layers.
