# Side navigation

A vertical list of links between the main areas of an app or documentation site, optionally in labeled groups. For a collapsible app sidebar, put it in a [Sidebar](/components/sidebar/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {SideNavigation} from '@earendil-works/elanor-react';

<SideNavigation.Root aria-label="Workspace">
  <SideNavigation.Group>
    <SideNavigation.GroupLabel />
    <SideNavigation.List>
      <SideNavigation.Item>
        <SideNavigation.Link href="/projects" active />
      </SideNavigation.Item>
    </SideNavigation.List>
  </SideNavigation.Group>
</SideNavigation.Root>;
```

Root renders a `nav`. `active` marks the current page with `aria-current="page"`. Groups are optional.

## Icons

`iconStart` and `iconEnd` add decorative icons; the label names the link.

<Demo example="./examples/icons.tsx" />

## Compact

`variant="compact"` shows only icons, with each label in a tooltip on hover and focus. Every link needs `iconStart`, `iconEnd`, or `compactContent`, such as initials; otherwise it throws. Labels and group labels stay available to screen readers.

Links with plain text are named from their text; give links with rich content an `aria-label`. Keep text-only documentation navigation expanded.

<Demo example="./examples/compact.tsx" />

Switching `variant` keeps the same links, so focus and tab order are preserved. [Sidebar](/components/sidebar/) switches it when the sidebar collapses.
