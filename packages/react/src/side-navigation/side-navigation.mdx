# Side navigation

A vertical list of links between the main areas of an app or documentation site, optionally in labeled groups. For a collapsible app sidebar, put it in a [Sidebar](/components/sidebar/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {SideNavigation} from '@earendil-works/elanor-react';

<SideNavigation.Root aria-label="Workspace">
  <SideNavigation.Group>
    <SideNavigation.GroupLabel />
    <SideNavigation.List>
      <SideNavigation.Item>
        <SideNavigation.Link href="/projects" active />
      </SideNavigation.Item>
    </SideNavigation.List>
  </SideNavigation.Group>
</SideNavigation.Root>;
```

Root renders a `nav`. `active` marks the current page with `aria-current="page"`: it gets the active fill and `semantic.color.text.primary` at `semantic.fontWeight.ui.selected`; other links are `semantic.color.text.secondary`. Groups are optional. Long labels wrap to two lines, then truncate.

## Sections

`Collapsible` holds a section that opens and closes, with a `CollapsibleTrigger` as its title and a `CollapsiblePanel` holding a `List` of links. It is built on Base UI's [Collapsible](https://base-ui.com/react/components/collapsible), like [Progressive disclosure](/components/progressive-disclosure/). Pass `defaultOpen` to the section that contains the current page, or control it with `open` and `onOpenChange`; its title is marked like the current page. Nested links indent their text by `semantic.dimension.space.padding.xLarge`.

The panel grows and shrinks to its measured height with `semantic.transition.movement.disclosure` and fades with `semantic.transition.fade`, the same in every browser; the height changes instantly when the reader prefers reduced motion. Closed panels stay in the document (`keepMounted`), so their links are part of the page's HTML.

## Compact

`variant="compact"` shows only icons, with each label in a tooltip on hover and focus. Every link needs `iconStart`, `iconEnd`, or `compactContent`, such as initials; otherwise it throws. Labels and group labels stay available to screen readers.

Links with plain text are named from their text; give links with rich content an `aria-label`. Keep text-only documentation navigation expanded.

<Demo example="./examples/compact.tsx" />

Compact navigation is one link wide: `semantic.dimension.size.medium` (32px). Switching `variant` keeps the same links, so focus and tab order are preserved. [Sidebar](/components/sidebar/) switches it when the sidebar collapses.
