# Emphasis

Stresses a word or phrase in running text, changing how the sentence reads. For importance rather than stress, use [Strong](/components/strong/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Emphasis} from '@earendil-works/elanor-react';

<Emphasis>not</Emphasis>;
```

Emphasis renders an `em` element in italics. Use it sparingly; for titles of works or terms in another language, use `cite` or `i` instead.
