# Dropdown

A button that opens a list of options to choose from, like a native select. Use it for one or more choices from a known list; add search when the list is long.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Dropdown} from '@earendil-works/elanor-react';

<Dropdown.Root>
  <Dropdown.Label />
  <Dropdown.Trigger>
    <Dropdown.Value />
    <Dropdown.Icon />
  </Dropdown.Trigger>
  <Dropdown.Portal>
    <Dropdown.Positioner>
      <Dropdown.Popup>
        <Dropdown.List>
          <Dropdown.Item />
        </Dropdown.List>
      </Dropdown.Popup>
    </Dropdown.Positioner>
  </Dropdown.Portal>
</Dropdown.Root>;
```

`Value` shows the selected value. When values differ from their labels, pass `items` to Root, such as `items={[{value: 'alpha', label: 'Alpha'}]}`.

The trigger stays on one line and truncates long values. Wrap its text in `Value` or an element, such as a `span`; bare text doesn't truncate and hides the icon.

Name the dropdown with `Label` above the trigger, or with [`Prefix`](#prefix) inside it. Screen readers announce the label as the name, then the selected value. Without a visible label, set `aria-label` on the trigger and include the value: it's the only text on the trigger, and people using speech input say what they see.

The popup opens below the trigger, aligned to its start edge, and repositions when space is limited. Set `alignItemWithTrigger` on Positioner to overlap the trigger with the selected item instead.

## Density

Use `compact` on the trigger in dense layouts, such as a filter beside a heading. It removes the block padding, so the trigger is one line of text high, with a smaller icon; the touch target keeps the default height. On touch screens it grows into half the medium gap above and below, so filters a medium gap apart don't overlap, and what's around it doesn't move. Clear's touch target does the same. The popup's items keep their size. `SearchableDropdown.Trigger` takes the same `density`.

## Prefix

`Prefix` labels the dropdown inside its trigger, before the value, such as a filter that reads "Date range: Last 30 days". Use it where there's no room for a label above, and keep it to a word or two. Pass the label without a colon: Prefix adds one after it, which screen readers skip, so the dropdown is named "Date range". The prefix is muted and stays whole; only the value truncates. Pressing it opens the popup, like the rest of the trigger.

Prefix and `Label` share the dropdown's one label, so use one of them. Don't set `aria-label` on the trigger as well; the label overrides it. Inside a `Field`, use Prefix instead of `Field.Label`.

## Clear

`Clear` is a button after the trigger that empties the dropdown and moves focus back to the trigger. It renders only while a value is selected. Put the trigger and Clear in `Control`, which joins them in one fill. Clear is a separate button, not part of the trigger, so it's the next stop when tabbing from the trigger.

Use Clear for filters, where no value means no filter. Don't use it on view controls that always have a value, such as a date range or a sort order.

Name Clear with `aria-label`, such as “Clear Status filter”, and show the empty value with `Value`'s `placeholder`, such as “All”. Clear calls Root's `onValueChange` with `null`, or an empty array with `multiple`, and the reason `clear-press`. It works with `value` and with `defaultValue`. A disabled or read-only Root, or a disabled `Field` or `Fieldset` around it, disables Clear.

<Demo example="./examples/clear.tsx" />

With `multiple`, Clear empties the array. To fit several values in a narrow trigger, show the first one and a count of the others, such as “Groups: developers +2”: render the first value with `Value`'s children, and the others' `count` in `ValueCount` after it. Like the prefix, the count is muted and stays whole while the value truncates. Screen readers read “developers and 2 more” instead; pass `label`, a function of the count, to translate it.

<Demo example="./examples/clear-multiple.tsx" />

### Clear to a default

Some filters start at a value other than none, such as API keys that show only active ones. Pass that default to Root as `clearValue`: Clear then shows while the value differs from it, including when nothing is selected, and sets it back with the reason `clear-press`. Name Clear for what it does, such as “Reset Status filter to Active”.

## Searchable

`SearchableDropdown` adds a filter input to the popup, which opens below the trigger aligned to its start edge, as Dropdown's does. Keep `Status` outside the popup so screen readers announce the selection after it closes. For a list that is always visible, see [Searchable list](/components/searchable-list/).

<Demo example="./examples/searchable.tsx" />

`SearchableDropdown` has the same `Prefix`, `ValueCount`, `Control` and `Clear`. Its `Value` renders no element of its own, so wrap it in a `span` to truncate it.
