# Dropdown

A button that opens a list of options to choose from, like a native select. Use it for one or more choices from a known list; add search when the list is long.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Dropdown} from '@earendil-works/elanor-react';

<Dropdown.Root>
  <Dropdown.Label />
  <Dropdown.Trigger>
    <Dropdown.Value />
    <Dropdown.Icon />
  </Dropdown.Trigger>
  <Dropdown.Portal>
    <Dropdown.Positioner>
      <Dropdown.Popup>
        <Dropdown.List>
          <Dropdown.Item />
        </Dropdown.List>
      </Dropdown.Popup>
    </Dropdown.Positioner>
  </Dropdown.Portal>
</Dropdown.Root>;
```

`Value` shows the selected value. When values differ from their labels, pass `items` to Root, such as `items={[{value: 'alpha', label: 'Alpha'}]}`.

The trigger stays on one line and truncates long values. Wrap its text in `Value` or an element, such as a `span`; bare text doesn't truncate and hides the icon.

Name the dropdown with `Label`, or with [`Prefix`](#prefix) inside the trigger. Without either, set `aria-label` on the trigger and include the value.

The popup opens below the trigger, aligned to its start edge, and repositions when space is limited. Set `alignItemWithTrigger` on Positioner to overlap the trigger with the selected item instead.

## Density

Use `compact` on the trigger in dense layouts, such as a filter beside a heading. The touch target keeps the default height. `SearchableDropdown.Trigger` takes the same `density`.

<Demo example="./examples/density.tsx" />

## Prefix

`Prefix` labels the dropdown inside the trigger, such as "Date range: Last 30 days". Use it when there's no room for `Label`, and keep it to a word or two. Prefix adds the colon, so leave it out of the text. Only the value truncates.

Use Prefix instead of `Label`, or instead of `Field.Label` inside a `Field`. It overrides `aria-label` on the trigger.

<Demo example="./examples/prefix.tsx" />

## Item indicator

`ItemIndicator` marks the selected item. Put the label next to it in `ItemText`.

<Demo example="./examples/item-indicator.tsx" />

## Multiple selection

With `multiple`, the value is an array and `ItemIndicator` shows a checkbox.

## Groups

`Group`, `GroupLabel`, and `Separator` divide long lists.

## Searchable

`SearchableDropdown` adds a filter input to the popup. Keep `Status` outside the popup so screen readers announce the selection after it closes. For a list that is always visible, see [Searchable list](/components/searchable-list/).
