# Dropdown

A button that opens a list of options to choose from, like a native select. Use it for one or more choices from a known list; add search when the list is long.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Dropdown} from '@earendil-works/elanor-react';

<Dropdown.Root>
  <Dropdown.Label />
  <Dropdown.Trigger>
    <Dropdown.Value />
    <Dropdown.Icon />
  </Dropdown.Trigger>
  <Dropdown.Portal>
    <Dropdown.Positioner>
      <Dropdown.Popup>
        <Dropdown.List>
          <Dropdown.Item />
        </Dropdown.List>
      </Dropdown.Popup>
    </Dropdown.Positioner>
  </Dropdown.Portal>
</Dropdown.Root>;
```

`Value` shows the selected value. When values differ from their labels, pass `items` to Root, such as `items={[{value: 'alpha', label: 'Alpha'}]}`.

The trigger stays on one line and truncates long values. Wrap its text in `Value` or an element, such as a `span`; bare text doesn't truncate and hides the icon.

Name the dropdown with `Label`, or with [`Prefix`](#prefix) inside the trigger. Without either, set `aria-label` on the trigger and include the value.

The popup opens below the trigger, aligned to its start edge, and repositions when space is limited. Set `alignItemWithTrigger` on Positioner to overlap the trigger with the selected item instead.

## Density

Use `compact` on the trigger in dense layouts, such as a filter beside a heading. The touch target keeps the default height, and on touch screens reaches into half the medium gap above and below. `SearchableDropdown.Trigger` takes the same `density`.

## Prefix

`Prefix` labels the dropdown inside the trigger, such as "Date range: Last 30 days". Use it when there's no room for `Label`, and keep it to a word or two. Prefix adds the colon, so leave it out of the text. Only the value truncates.

Use Prefix instead of `Label`, or instead of `Field.Label` inside a `Field`. It overrides `aria-label` on the trigger.

<Demo example="./examples/prefix.tsx" />

## Clear

`Clear` is a button after the trigger that clears the value and moves focus back to the trigger. It renders only while there's something to clear. Put the trigger and Clear in `Control`, which joins them in one fill; Clear is the next tab stop after the trigger.

Use Clear on filters, where no value means no filter, not on view controls that always have a value, such as a date range or a sort order.

Name Clear with `aria-label`, such as “Clear Status filter”, and show the empty value with `Value`'s `placeholder`, such as “All”. Clear calls `onValueChange` with `null`, or `[]` with `multiple`, and the reason `clear-press`. A disabled or read-only Root, or a disabled `Field` or `Fieldset`, disables it. Its touch target matches the trigger's.

<Demo example="./examples/clear.tsx" />

With `multiple`, Clear empties the array.

### Clear to a default

For a filter that starts at a value, such as API keys that show only active ones, pass the default to Root as `clearValue`. Clear then shows while the value differs from it, including when nothing is selected, and sets it back. Name it for what it does, such as “Reset Status filter to Active”.

<Demo example="./examples/clear-default.tsx" />

## Value count

`ValueCount` shows how many more values are selected, such as “Groups: developers +2”. Render the first selected value with `Value`'s children and put ValueCount after it. It counts from Root unless you pass `count`, and stays whole while the value truncates. Screen readers read “developers and 2 more”; pass `label` to translate it.

<Demo example="./examples/value-count.tsx" />

## Searchable

`SearchableDropdown` adds a filter input to the popup, aligned like Dropdown's. Keep `Status` outside the popup so screen readers announce the selection after it closes. For a list that is always visible, see [Searchable list](/components/searchable-list/).

<Demo example="./examples/searchable.tsx" />

`SearchableDropdown` has the same `Prefix`, `ValueCount`, `Control` and `Clear`. Its `Value` renders no element, so wrap it in a `span` to truncate it.
