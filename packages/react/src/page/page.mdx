# Page

Stacks a page's content with consistent spacing (`semantic.dimension.space.gap.large`, 24px). It renders a `div`, not a landmark.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Container, Layout, Page} from '@earendil-works/elanor-react';

<Layout.Main>
  <Container>
    <Page>{/* Page header, sections, and content */}</Page>
  </Container>
</Layout.Main>;
```

[Layout.Main](/components/layout/) provides the main landmark and [Container](/components/container/) the width; Page only spaces its children. Give the page title `level={1}`; the demo uses `level={2}` because this page already has an H1.
