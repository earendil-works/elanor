# Link

Navigates to another page or location. For actions that don't navigate, use [Button](/components/button/).

Links use `semantic.typography.primary` like [Text](/components/text/), so they match the text around them in UI and in long-form content (`data-text-context="prose"`).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Link} from '@earendil-works/elanor-react';

<Link href="/guides/onboarding">Onboarding guide</Link>;
```

Write link text that makes sense out of context; avoid "click here".

## New tab

Open a new tab only when leaving would interrupt a task. Say so in the link text and set `rel="noreferrer"`.
