# Key value

Shows labeled values, such as the details of a record. Renders a description list (`<dl>`).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {KeyValue} from '@earendil-works/elanor-react';

<KeyValue.Grid>
  <KeyValue.Key>Status</KeyValue.Key>
  <KeyValue.Value>Active</KeyValue.Value>
</KeyValue.Grid>;
```

`KeyValue.Grid` aligns keys and values in two columns. Keys get a trailing colon; don't add your own.

## Inline

`KeyValue.Inline` keeps a pair on one line and wraps when space runs out.
