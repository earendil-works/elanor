# Blockquote

A quotation from another source, set apart from the surrounding text by an indent and a rule.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Blockquote, Text} from '@earendil-works/elanor-react';

<Blockquote>
  <Text />
</Blockquote>;
```

Blockquote renders a `blockquote` with a `semantic.dimension.borderWidth.medium` rule in `semantic.color.border.primary` and a `semantic.dimension.space.padding.xxLarge` (24px) indent. It sets no type of its own: put [Text](/components/text/) or other blocks inside.

## Source

Name the source in the text around the quotation, or in a `figcaption` when the quotation sits in a `figure`. Put a source URL in `cite`; browsers don't show it.
