# Checkbox

A control for turning an option on or off, or for selecting several items from a list. For one choice from a set, use [Radio](/components/radio/); for a setting that applies immediately, use [Switch](/components/switch/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Checkbox, SelectionControlAndLabel} from '@earendil-works/elanor-react';

<SelectionControlAndLabel
  control={
    <Checkbox.Root>
      <Checkbox.Indicator />
    </Checkbox.Root>
  }
>
  Include archived projects
</SelectionControlAndLabel>;
```

[Selection control and label](/components/selection-control-and-label/) makes the whole label clickable.

## Group

`Checkbox.Group` holds the values of the checked options in one array. Label it with [Fieldset](/components/fieldset/).

<Demo example="./examples/group.tsx" />

## Indeterminate

In a group, a `parent` checkbox checks or clears every option and is indeterminate when only some are checked. Pass every option to the group's `allValues`. Outside a group, set `indeterminate` yourself.
