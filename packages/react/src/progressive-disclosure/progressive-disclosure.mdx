# Progressive disclosure

A button that shows and hides a panel of secondary content, such as advanced options. Keeps the default view short.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {ProgressiveDisclosure} from '@earendil-works/elanor-react';

<ProgressiveDisclosure.Root>
  <ProgressiveDisclosure.Trigger />
  <ProgressiveDisclosure.Panel />
</ProgressiveDisclosure.Root>;
```

`defaultOpen` starts the panel open; `open` and `onOpenChange` control it.

## Keep content mounted

A closed panel unmounts its content, so unsaved input is lost. `keepMounted` keeps it: edit the field, close the panel, and reopen it.
