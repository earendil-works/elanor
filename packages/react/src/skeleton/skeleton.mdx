# Skeleton

A placeholder in the shape of content that is still loading, so the layout doesn't shift when it arrives. For waits longer than a few seconds, show a status message instead.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Skeleton, SkeletonText} from '@earendil-works/elanor-react';

<Skeleton loading={!user}>{user?.name ?? 'Placeholder name'}</Skeleton>;
<SkeletonText lines={3} />;
```

Skeleton covers its content in `semantic.color.background.skeleton` and pulses with `semantic.transition.pulse`. The content keeps its size but is hidden from screen readers and keyboard focus, so set `aria-busy` on the region that is loading. Skeleton renders a `span`; use `render={<div />}` around blocks.

When the children are only text (strings or numbers, not elements or fragments), each line of it gets a bar as tall as the capitals, on the baseline, and the element keeps its size. Around other children, such as a [Button](/components/button/) or a [Card](/components/card/), the placeholder covers the whole element. Text bars are square, as text has no corners; the placeholder of other children keeps rounded corners.

## Loading

`loading` switches between the placeholder and the content in the same element, without a layout shift.

<Demo example="./examples/loading.tsx" />

## Delay

Skeleton and SkeletonText reserve their space but stay hidden for `semantic.duration.loading.delay`. The delay starts when Skeleton's `loading` becomes true or SkeletonText mounts, so fast loads skip the placeholder. It defaults to `0ms`. Set it on the container whose content loads; set it at `:root` only when every skeleton in your project should wait:

```css
/* Only the skeletons inside the activity feed */
.activity-feed {
  --semantic-duration-loading-delay: 300ms;
}

/* Every skeleton in your project */
:root {
  --semantic-duration-loading-delay: 300ms;
}
```

## Text

SkeletonText shows placeholder lines in the size of the surrounding text, each a bar as tall as the capitals on the baseline. Put it inside [Text](/components/text/) or [Heading](/components/heading/). In a [Stack](/components/stack/), use `align="stretch"` so the lines fill the width.
