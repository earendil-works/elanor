# Sidebar

A desktop app sidebar that collapses to a rail of icons and stays usable when collapsed. On small screens, show the same destinations in a [Drawer](/components/drawer/) instead; see the [responsive navigation recipe](/components/top-navigation/#responsive-navigation).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Layout, SideNavigation, Sidebar} from '@earendil-works/elanor-react';

<Sidebar.Root render={<Layout.Aside aria-label="Workspace sidebar" />}>
  {({collapsed}) => (
    <>
      <Sidebar.Header>
        <Sidebar.Trigger />
      </Sidebar.Header>
      <Sidebar.Content>
        <SideNavigation.Root variant={collapsed ? 'compact' : 'default'} />
      </Sidebar.Content>
      <Sidebar.Footer />
    </>
  )}
</Sidebar.Root>;
```

- **Root** renders a `div`; render it as `Layout.Aside` for a single aside landmark. Its children can be a function that receives `{collapsed}`.
- **Header** and **Footer** stay in place. Keep Trigger in the Header so it can't scroll out of reach.
- **Content** scrolls. Its `ref`, props, and scroll events go to the scrolling element.
- Every region exposes `data-collapsed` while collapsed, and its `render` and `className` callbacks receive `{collapsed}`.

## Compact content

Set `variant={collapsed ? 'compact' : 'default'}` on each [Side navigation](/components/side-navigation/), and give every link an icon or `compactContent` in both states. Don't swap in a different navigation tree when collapsing; the same links keep focus, tab order, and `aria-current`.

Collapsed links show their label in a tooltip on hover and focus. Branding, project switchers, and account controls need their own compact form: keep the same control mounted and change only its decorative content. Before removing a control that only exists when expanded, move focus to one that persists.

## Controlled

Pass `collapsed` and `onCollapsedChange` to control the state, for example to persist it. `details.cancel()` in `onCollapsedChange` keeps the current state; a controlled owner that cancels must not update its own state either. Don't switch between controlled and uncontrolled.

## Trigger

The trigger is a Base UI Toggle named "Collapse sidebar". `aria-pressed="true"` means collapsed. For other languages, override `aria-label` with one label that stays the same in both states; the tooltip only supplements it. It exposes `data-pressed`, not `data-collapsed`.

## Size and scrolling

The sidebar is `semantic.dimension.size.sidebar` (210px) wide when expanded and `semantic.dimension.size.xLarge` (48px) when collapsed, including its 4px divider. Override the widths with CSS.

Root is at most `100dvh` tall; reduce `maxBlockSize` below a sticky header. Set `blockSize` to fill the height even with little content.

The Content scrollbar appears while scrolling, not on hover. A fade at the bottom and a line at the top show there is more content; keyboard focus replaces the fade with a line so links stay visible.

Render the same collapsed state on the server and the client. For right-to-left layouts, set Base UI's `DirectionProvider` to the document direction. On touch screens, don't rely on tooltips to explain icons.
