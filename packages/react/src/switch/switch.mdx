# Switch

Turns a setting on or off, taking effect immediately. For choices that apply when a form is submitted, use [Checkbox](/components/checkbox/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {SelectionControlAndLabel, Switch} from '@earendil-works/elanor-react';

<SelectionControlAndLabel
  control={
    <Switch.Root>
      <Switch.Thumb />
    </Switch.Root>
  }
>
  Desktop notifications
</SelectionControlAndLabel>;
```
