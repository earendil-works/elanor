# Radio

A set of options where exactly one can be selected. For two to five visible options, use Radio; for longer lists, use [Dropdown](/components/dropdown/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Fieldset, Radio, SelectionControlAndLabel} from '@earendil-works/elanor-react';

<Fieldset.Root render={<Radio.Group />}>
  <Fieldset.Legend>Email digest</Fieldset.Legend>
  <SelectionControlAndLabel
    control={
      <Radio.Root value="daily">
        <Radio.Indicator />
      </Radio.Root>
    }
  >
    Daily
  </SelectionControlAndLabel>
</Fieldset.Root>;
```

Label the group with [Fieldset](/components/fieldset/). Arrow keys move between options.

## Disabled

Disable a single option with `disabled` on `Radio.Root`, or the whole group on `Fieldset.Root`.
