# Card

A padded block that groups related content, such as a summary metric or a set of settings. It has no border or background of its own.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Card} from '@earendil-works/elanor-react';

<Card label="Active projects" value="12" description="Across three teams" />;
```

`label`, `value`, and `description` lay out a summary metric. Children replace that layout.
