# Card

A padded block that groups related content, such as a summary metric or a set of settings. It has no border or background of its own unless it is a link.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Card} from '@earendil-works/elanor-react';

<Card label="Active projects" value="12" description="Across three teams" />;
```

`label`, `value`, and `description` lay out a summary metric. Children replace that layout.

## Link

Use `render={<a href="…" />}` to make the whole card a link. Linked cards get a border, so the whole target is visible.

<Demo example="./examples/link.tsx" />

The link's accessible name is all of the card's text, so keep it short. Don't put other links or buttons inside; use [custom content](#custom-content) with a separate link instead.
