# Control and label

Labels a text control, such as [Input](/components/input/) or [Text area](/components/text-area/), with an optional description and error. For checkboxes, radios, and switches, use [Selection control and label](/components/selection-control-and-label/).

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {ControlAndLabel, Input} from '@earendil-works/elanor-react';

<ControlAndLabel label="Display name" description="Shown to other workspace members.">
  <Input name="displayName" />
</ControlAndLabel>;
```

ControlAndLabel is shorthand for these [Field](/components/field/) parts. Use Field directly for a different order or one message per validation rule.

```tsx
<Field.Root>
  <Field.Label>Display name</Field.Label>
  <Input name="displayName" />
  <Field.Description>Shown to other workspace members.</Field.Description>
  <Field.Error />
</Field.Root>
```

## Error

`error` appears when the control fails native validation, such as `required` or `type="email"`. Here, validation runs when focus leaves the field: focus it, then press Tab.

## Disabled

`disabled` disables the label, description, and control together.
