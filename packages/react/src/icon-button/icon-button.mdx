# Icon button

A button that shows only an icon, for compact or frequently repeated actions. When space allows, prefer a [Button](/components/button/) with a visible label.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {SettingsIcon} from '@earendil-works/elanor-icons-react';
import {IconButton} from '@earendil-works/elanor-react';

<IconButton aria-label="Workspace settings">
  <SettingsIcon />
</IconButton>;
```

Icons are decorative by default, so the button needs an `aria-label`. To show the label on hover and focus, wrap the button in a [Tooltip](/components/tooltip/).

## Density

Unlike [Button](/components/button/), icon buttons default to `density="compact"`: the fill is the icon's size, for dense rows and toolbars. `density="default"` is the icon plus control padding, as tall as a default Button, for buttons that stand alone, such as a composer's.

<Demo example="./examples/density.tsx" />

## Hierarchy

`tertiary`, the default, has no fill until hovered or pressed. `primary` has the primary fill, as on [Button](/components/button/), for the one main action of a view, such as sending a message. `secondary` has a surface and a hairline, for a button floating over content, such as one that scrolls to the latest message. Use `primary` and `secondary` with `density="default"`.
