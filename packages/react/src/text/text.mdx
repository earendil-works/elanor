# Text

Text renders a paragraph by default. Use `render={<span />}` for inline text;
put element-specific attributes and refs on the rendered element.

## Paragraph

<Text>Keep your team's projects, shared documents, and decisions in one place.</Text>

## Inline

<TextInlineExample />

```tsx
<p>
  Project visibility: <Text render={<span />}>Private</Text>
</p>
```
