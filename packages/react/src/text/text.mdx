# Text

Body text. Renders a paragraph by default.

Text uses `semantic.typography.primary`, the UI style by default and the prose style inside long-form content (`data-text-context="prose"`). Paragraphs stop at `semantic.dimension.size.maxWidth.text` (52rem) so lines stay readable in wide layouts; inline text has no limit.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Text} from '@earendil-works/elanor-react';

<Text>Keep your team's projects in one place.</Text>;
```

## Inline

Use `render={<span />}` inside other text. Put element-specific attributes and refs on the rendered element.

<Demo example="./examples/inline.tsx" />

## Long-form content

Inside an element with `data-text-context="prose"`, Text and [Link](/components/link/) switch to the prose style.
