# Text

Body text in the UI typeface. Renders a paragraph by default.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Text} from '@earendil-works/elanor-react';

<Text>Keep your team's projects in one place.</Text>;
```

## Inline

Use `render={<span />}` inside other text. Put element-specific attributes and refs on the rendered element.
