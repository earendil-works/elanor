# Code snippet

Shows a short piece of code or a command, such as an install step. Long lines scroll horizontally.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {CodeSnippet} from '@earendil-works/elanor-react';

<CodeSnippet>pnpm install</CodeSnippet>;
```

Pass a [Copy button](/components/copy-button/) to `actions`.
