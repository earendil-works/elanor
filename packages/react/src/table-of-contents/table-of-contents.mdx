# Table of contents

Links to the sections of the current page, usually in a side region of a long page.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {TableOfContents} from '@earendil-works/elanor-react';

<TableOfContents.Root>
  <TableOfContents.List>
    <TableOfContents.Item>
      <TableOfContents.Link href="#usage" active>
        Usage
      </TableOfContents.Link>
    </TableOfContents.Item>
  </TableOfContents.List>
  <TableOfContents.Indicator />
</TableOfContents.Root>;
```

The demo links point to sections of this page. Root renders a `nav` named "Table of contents". `List` renders an ordered list, at the top and for nested entries.

## Current section

`active` marks the section in view with `aria-current="location"`: its text turns `semantic.color.text.primary`, and the `Indicator`, a bar on the list's start edge, marks it. When `active` moves to another entry, the indicator slides there and resizes with `semantic.transition.movement.tableOfContents.indicator`, overshooting slightly; instantly when the reader prefers reduced motion. The application decides which section is current, for example with an `IntersectionObserver`. In the demo, choosing an entry makes it current.

<Demo example="./examples/active.tsx" />

## Nested sections

Put another `List` inside an `Item`, after its `Link`, for subsections. Nested entries indent only their text, so the bar stays on the same edge.
