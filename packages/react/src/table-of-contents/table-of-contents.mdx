# Table of contents

Links to the sections of the current page, usually in a side region of a long page.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {TableOfContents} from '@earendil-works/elanor-react';

<TableOfContents.Root>
  <TableOfContents.List>
    <TableOfContents.Item>
      <TableOfContents.Link href="#usage" active>
        Usage
      </TableOfContents.Link>
    </TableOfContents.Item>
  </TableOfContents.List>
  <TableOfContents.Indicator />
</TableOfContents.Root>;
```

The demo links point to sections of this page. Root renders a `nav` named "Table of contents". `List` renders an ordered list, at the top and for nested entries.

## Current section

`active` marks the section in view with `aria-current="location"`: its text turns `semantic.color.text.primary`, and the `Indicator`, a bar on the list's start edge, marks it. When `active` moves to another entry, the indicator slides there and resizes with `semantic.transition.movement.tableOfContents.indicator`, overshooting slightly; instantly when the reader prefers reduced motion. The application decides which section is current, for example with an `IntersectionObserver`. In the demo, choosing an entry makes it current.

<Demo example="./examples/active.tsx" />

## Nested sections

Put another `List` inside an `Item`, after its `Link`, for subsections. Nested entries indent only their text, so the bar stays on the same edge.

## Menu

For layouts without room for the list beside the content, `Menu` collapses the table of contents into a bar with a dropdown. `MenuTrigger` shows the current section; `MenuPopup` holds the same `List`, `Item`, and `Link` parts, which look like dropdown items there, and choosing a link closes it. The list also closes when the page scrolls.

<Demo example="./examples/menu.tsx" />

```tsx
<TableOfContents.Menu>
  <TableOfContents.MenuTrigger>Current section</TableOfContents.MenuTrigger>
  <TableOfContents.MenuPopup>
    <TableOfContents.List />
  </TableOfContents.MenuPopup>
</TableOfContents.Menu>
```

Keep the trigger's text in sync with the `active` link. Assistive technology hears "Table of contents: " before it; change that with the trigger's `label`, and the list's name with the popup's `label`.

The menu is a bar with separators above and below that sticks to the top of its scroll container, on `semantic.number.layer.floating`, with a shadow that fades in as content scrolls beneath it. To stick below a header, set `inset-block-start` in your CSS, such as `calc(var(--semantic-dimension-size-top-navigation) - var(--semantic-dimension-border-width-small))` below a top navigation: the bar sticks one border width higher, so the header's border covers its top separator.
