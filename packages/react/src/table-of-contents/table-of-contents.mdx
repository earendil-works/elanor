# Table of contents

Links to the sections of the current page, usually in a side region of a long page.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {TableOfContents} from '@earendil-works/elanor-react';

<TableOfContents.Root>
  <TableOfContents.Item>
    <TableOfContents.Link href="#usage">Usage</TableOfContents.Link>
  </TableOfContents.Item>
</TableOfContents.Root>;
```

The demo links point to sections of this page. Root renders a `nav` named "Table of contents" with an ordered list. The visible title defaults to "On this page"; change it with `title`.

## Current section

`active` marks the section in view with `aria-current="location"`: its text turns `semantic.color.text.primary`, and a bar marks it on the list's start edge. Other entries are `semantic.color.text.secondary` until hovered. The application decides which section is current, for example with an `IntersectionObserver`.

<Demo example="./examples/active.tsx" />

## Nested sections

Put a `List` inside an `Item`, after its `Link`, for subsections. Nested entries indent only their text, so the bar stays on the same edge.

<Demo example="./examples/nested.tsx" />

## Without a title

`title={null}` shows no title, for example when a heading next to it already names the list. The `nav` keeps its accessible name.
