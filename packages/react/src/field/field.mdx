# Field

Connects a label, a control, help text, and validation messages, so assistive technology announces them together. For a label, description, and single error, [Control and label](/components/control-and-label/) is shorter.

<Demo example="./examples/demo.tsx" />

## Usage

```tsx
import {Field, Input} from '@earendil-works/elanor-react';

<Field.Root name="email">
  <Field.Label>Email</Field.Label>
  <Input type="email" />
  <Field.Description />
  <Field.Error />
</Field.Root>;
```

## Validation

Field uses the control's native validation, such as `required` and `type="email"`. Give each `Field.Error` a `match` to show one message per failed rule. `validationMode="onBlur"` validates when focus leaves the control; the default validates on form submit.
