# Top navigation

Recipes composed from `TopNavigation` parts. They are application-owned compositions, not component variants; copy the arrangement and styles you need.

## Inline

Identity, links and actions share a row and wrap when needed.

## Centered

## Responsive navigation

Desktop [Sidebar](/components/sidebar/) and inline resources become a mobile [Drawer](/components/drawer/) below `semantic.dimension.breakpoint.medium`. Both share destinations and selection; desktop collapse stays independent. Try resizing with the drawer open.
